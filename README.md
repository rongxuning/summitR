# SummitR

一个像素风格的 CrossFit 健身应用，采用星露谷风格的视觉设计。

## 功能特性

- 🎮 像素风格界面设计
- 💪 多种 CrossFit 运动动画展示
- 🏋️ 动态人物动画效果
- 🏋️‍♀️ 健身房场景背景

## 技术栈

- SwiftUI
- iOS 16+

## 项目结构

```
SummitR/
├── SummitRApp.swift          # 应用入口
├── ContentView.swift          # 主视图
├── Views/
│   ├── CoverPageView.swift    # 封面页面
│   ├── GymBackgroundView.swift # 健身房背景
│   └── PixelPersonView.swift  # 像素风格人物组件
└── Info.plist                 # 应用配置
```

## 运动类型

- 杠铃深蹲 (Squat)
- 杠铃硬拉 (Deadlift)
- 平板支撑 (Plank)
- 俯卧撑 (Pushup)
- 引体向上 (Pullup)
- 划船 (Row)
- 单车 (Bike)

## 运行要求

- Xcode 14.0+
- iOS 16.0+
- Swift 5.9+

## 安装

1. 使用 Xcode 打开项目
2. 选择目标设备或模拟器
3. 运行项目 (⌘R)

## 开发

项目使用 SwiftUI 构建，采用声明式 UI 和响应式设计模式。
